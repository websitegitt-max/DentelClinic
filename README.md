A production-grade, single-file dental clinic website with appointment booking and direct WhatsApp cancellation notifications.

## Key Features
1. **Zero-Build Deployment:** Single standalone `index.html` file powered by React and Tailwind CDN. No Node.js or `npm` required.
2. **Appointment Bag / Drawer:** Patients can pick treatments, book slots, and view active reservations.
3. **Cancellation via WhatsApp:** Canceling an appointment automatically prepares a formatted WhatsApp notification to `7782962661`.
4. **Before & After Interactive Slider:** Touch- and mouse-responsive visual comparison slider.
5. **Infrastructure Gallery:** Responsive facility gallery with interactive fullscreen lightbox.

## Deployment on GitHub Pages
1. Upload `index.html` and `README.md` to your GitHub repository root.
2. Go to **Repository Settings** → **Pages**.
3. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
4. Select `main` branch and `/(root)` directory, then click **Save**.
